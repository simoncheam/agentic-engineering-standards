# Feature Development Workflow

> **Status:** 🚧 In progress — being extracted from practice. Skeleton only.

Extends the bug-resolution workflow to net-new work: spec → plan → review gate → implementation → review gate → verification → release.

## To document

- [ ] Spec: turning a feature request into an implementable specification

- [ ] Incremental implementation: slicing work so each slice is reviewable
- [ ] Review gates: plan-level and change-level
- [ ] Verification: exercising the feature end to end, not just its tests
