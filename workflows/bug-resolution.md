# Bug Resolution Workflow

> **Status:** 🚧 Being documented from daily practice. Do not treat as complete.

The mature workflow: intake → reproduction → investigation → plan → review gate → implementation → review gate → verification.

## To document

- [ ] Intake: what a well-formed bug report contains before work starts
- [ ] Reproduction: the bug must be reproduced before it is diagnosed
- [ ] Investigation: evidence-gathering rules (read before hypothesize)
- [ ] Plan + review gate: what the engineer approves before implementation
- [ ] Implementation: constraints (smallest change that fixes the cause, not the symptom)
- [ ] Review gate: what the engineer checks before the change is accepted
- [ ] Verification: demonstrating the fix against the original reproduction
